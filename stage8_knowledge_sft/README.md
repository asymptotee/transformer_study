# 阶段八：知识问答 SFT —— "记忆会，检索不会"

## 目标

阶段六做过 SFT（鲁迅基座）：格式学会了，知识没有——因为语料里根本没有知识。
阶段七换了维基百科预训练（100M 模型，4400 万 token），知识应该"注入"了。
本阶段做 SFT，验证：

1. SFT 能不能把"预训练注入的知识"接通成"回答问题"的能力？
2. 全量 vs LoRA 在 100M 百科基座上是否仍接近？
3. 知识边界现在在哪里？

## 数据：从维基语料构造问答对（`make_qa.py`）

从 150MB 维基语料抽出含"是"的句子、在逗号处切两半，配 3 种问法模板：

```
问：请补全这句话："北京是"   答：中华人民共和国的首都，简称京。
```

共切出 **195,103 个句对**，训练 60,000 + 测试 1,000（与阶段六同格式）。

评估数据是 **20 道常识题**（`eval_facts.py` 内置）：高频 10 题（北京↔首都这种
强共现）+ 低频 10 题（化学式、年份这类），并支持两种提问格式：
`ask`（"中国的首都是哪里？"）和 `fill`（补全格式，与训练分布一致）。

## 训练

| | 可训练参数 | test loss（4.53 →） | 时长 |
|---|---|---|---|
| 全量 SFT | 96,634,368（100%） | **3.87** | ~4 分钟 |
| LoRA SFT | ~1%（32,768×2 适配器） | **4.03** | ~4 分钟 |

**LoRA 再次用约 1% 参数接近全量**（阶段六的结论在 100M 基座上复现）。
工程上修了一个坑：BPE 编码单进程要 40+ 分钟 → 多进程（fork，必须在加载
CUDA 模型之前）→ 90 秒。

## 评估结果：20 道常识题全军覆没

| 格式 | 基座 | 全量 SFT | LoRA |
|---|---|---|---|
| 问句（"首都是哪里？"） | 1/20* | 0/20 | 1/20* |
| 补全（"中国的首都是"） | 1/20* | 0/20 | 2/20 |

（\* 假阳性：重复 prompt 含"秦"字被关键词匹配算对；真实答对率 ≈ 0）

典型回答：问"中国的首都是哪里？"→ 答"中国的首都"——**格式对了，内容空了**。

## 三层归因

1. **测试题不在语料分布里（最致命）**：维基百科不写"中国的首都是北京"这种
   问答句式，它写"北京是中华人民共和国的首都"。模型（和训练数据）从没见过
   "中国的首都是"这个前缀——接不出"北京"不是笨，是没读过。
2. **100M 模型的检索上限**：预训练注入的知识是 embedding 里的模糊关联，
   不是事实数据库；生成时从 4400 万 token 分布里"定点提取"答案，是
   100M 模型做不到的（真实 LLM 靠千亿参数 + 万亿 token 才有这个能力）。
3. **评估设计偏差**：预期"高频答对一半"过于乐观，高估了小模型。

## 正面结论（机制依然验证成立）

- **SFT 行为可教 ✓**：基座回答空/重复 prompt，SFT 后都会生成"百科句式短语"
  （"中国的首都，位于…"）——格式转变第三次验证。
- **LoRA ≈ 全量 ✓**：test loss 3.87 vs 4.03，1% 参数接近全量，第三次复现。
- **知识以"原句复现"存在 ✓**：LoRA 答对"故宫位于→北京"——语料里高频
  精确出现的句子能被记住和复现。记忆会，检索不会。

## 文件

| 文件 | 内容 |
|---|---|
| `make_qa.py` | 维基语料 → 补全式问答对（qa_train/qa_test.jsonl） |
| `train_sft7.py` | SFT 训练（loss 掩码、全量/LoRA、多进程编码、--device） |
| `eval_facts.py` | 20 道常识题评估（--format ask/fill） |
| `chat8.py` | 交互式问答（--model full/lora/base） |
| `ckpt_sft7_full.pt / ckpt_sft7_lora.pt` | 两个 SFT 模型 |

## 运行

```bash
cd stage8_knowledge_sft
PY=python    # DGX Spark 上的 venv

$PY -u make_qa.py                       # 造问答数据（60k 训练 + 1k 测试）
$PY -u train_sft7.py                    # 全量 SFT（~4 分钟）
$PY -u train_sft7.py --lora             # LoRA SFT（~4 分钟）
$PY -u eval_facts.py                    # 20 题评估（问句格式）
$PY -u eval_facts.py --format fill      # 20 题评估（补全格式）
$PY -u chat8.py                         # 交互问答
```

## 这一阶段说明了什么

把 CONCEPTS.md 的"预训练注入知识、SFT 激发行为"推到了它的边界：

- **SFT 激发行为：真**（第三次验证，格式必然学会）
- **预训练注入知识：半真**——知识以模糊关联和原句复现存在（"故宫位于北京"
  能复现），但**不能以问答检索的形式取出**。要跨过这道检索之坎：要么规模再
  大几个数量级（真实 LLM 的路），要么换思路——**RAG**（把知识放进 prompt，
  不靠模型记，靠模型读）。

"记忆会，检索不会"——这就是 100M 模型的诚实画像，也是本阶段想留下的结论。
