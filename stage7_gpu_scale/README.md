# 阶段七：GPU 规模训练 —— 规模翻越"连贯之坎"

## 目标

阶段五的结论是"风格能学到极致，**连贯却跨不过去**——那道坎要靠规模涌现"。
本阶段第一次离开 CPU，在 **DGX Spark（NVIDIA GB10）** 上把规模推上去，验证两个命题：

1. **连贯之坎**：更大的模型 + 更大的语料，生成能不能从"乱语"变成"通顺句子"？
2. **知识注入**：预训练语料换成维基百科，事实知识会不会以某种形式进到模型里？

## 环境与语料

- **硬件**：DGX Spark，GB10（128GB 统一内存），CUDA 13.0，torch 2.13.0+cu130
- **语料**：中文维基百科 dump（20260801 第一段，241MB）→ wikiextractor 提取 →
  opencc 繁转简 → 过滤短文 → **150MB / 18,421 篇文章**（`corpus_wiki.jsonl`）
- 语料管线：`build_corpus.py`（提取 22s + 清洗切片几分钟）

## 两次训练

### 探路（30M / 2000 步 / 30MB）——验证管线

| 项目 | 数值 |
|---|---|
| 模型 | 30.9M（d512 / 8层 / 8头） |
| val loss | 5.23（perplexity ≈ 187） |
| 吞吐 | 5.9 step/s，6 分钟跑完 |
| 效果 | 词级关联学到（数学↔向量/矩阵），句子乱码，事实全错 |

探路的意义：语料管线通、GPU 吞吐可估、BPE 编码缓存机制验证（30MB 一次性
编码 222s 存盘，之后秒加载）。

### 全量（96.6M / 10000 步 / 150MB）——正式实验

| 项目 | 数值 |
|---|---|
| 模型 | 96.6M（d768 / 12层 / 12头 / d_ff 3072），词表 15,124 |
| 语料 | 43.9M 训练 token（BPE 3000 merges） |
| 训练 | bf16 AMP + AdamW + 500 warmup + cosine，batch 32×256 |
| 吞吐 / 时长 | 2.6 step/s，**64 分钟** |
| **val loss** | **3.826**（perplexity ≈ 46，探路的 1/4） |

## 结果：连贯之坎跨过了

| prompt | 探路（30M） | 全量（100M） |
|---|---|---|
| 【北京是】 | "北京是中心的书馆，并于东南京市之一" | "北京是中国东北地区重要的经济支柱产业。此外，秦岭山脉大部分地区在…" |
| 【数学是】 | "数学是分析的知识分子…" | "数学是他的数学贡献者。费马赫在完成了一个数学原理的早期工作…" |
| 【水是一种】 | "水是一种这些可有原始的海峡岸线…" | "水是一种稀有气体，根据氧化氢的形态和原子序数来定义…" |

- **句子层全通**：语法正确、百科语气、"天文学家 Mark Oser 在 2003 年发表了《千年梦》"这种结构完美的句子
- **知识层错误但有规律**：模型学会"X 位于 Y 市，市人民政府驻 Z 路"这类**模板**，往里填错参数——"模板 + 高频填充"，不是事实
- **个别高频原句复现**：训练中途"长城位于"曾答出"北京市西南部"

## 关键工程数字

| 项目 | 数值 |
|---|---|
| BPE 编码 150MB | 991s（10 进程），一次性缓存（`cache/tokens.pt`） |
| 训练时长 | 64 分钟（10000 步） |
| GPU 利用率 | 96% |
| 内存 | 128GB 无压力（峰值 ~3GB） |

## 文件

| 文件 | 内容 |
|---|---|
| `build_corpus.py` | dump → 提取 → 繁转简 → 切片成 JSONL 语料 |
| `train_large.py` | 训练主脚本（bf16 + warmup/cosine + 编码缓存 + best-ckpt） |
| `eval_ckpt.py` | 固定 prompt 生成评估 |
| `chat7.py` | 交互式续写（`--ckpt` 切换模型） |
| `probe_v1/` | 探路实验完整存档（模型+词表+语料，可复现） |
| `data/zhwiki-*.bz2` | 维基 dump（下载一次，可继续提取更多语料） |

## 运行

```bash
cd stage7_gpu_scale
PY=python    # DGX Spark 上的 venv

$PY -u build_corpus.py --dump data/zhwiki-20260801-p1.bz2 --max-mb 150
$PY -u train_large.py --corpus corpus_wiki.jsonl --steps 10000 \
    --d-model 768 --n-layers 12 --n-heads 12 --d-ff 3072 --ckpt ckpt_large.pt
$PY -u eval_ckpt.py --ckpt ckpt_large.pt
$PY -u chat7.py --ckpt ckpt_large.pt           # 交互续写
```

## 这一阶段说明了什么

- **规模跨过了"连贯之坎"**：30M→100M + 30MB→150MB，perplexity 降 4 倍，
  生成从"乱语"到"通顺句子"——阶段五的结论在更大尺度上验证成立。
- **知识以两种形式存在，但都不是"可检索"**：模糊关联（embedding 共现）
  和原句复现（高频 chunk 记住）——这就是下一阶段（stage8）要面对的现实：
  100M 模型"记得住"知识，却"答不出"问题。
- **训练量仍是短板**：10000 步只看了 1.8 个 epoch；语料还有 4 倍可提取
  （dump 只用了第一段），想继续推效果，扩语料 + 加步数是现成的路。
