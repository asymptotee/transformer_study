# 阶段六：SFT 指令微调 —— 从"续写"到"应答"（全量 vs LoRA）

## 目标

阶段五训出的是一个**基座模型**：给它开头，它只会**续写**。这一阶段做
`CONCEPTS.md` 第九、十节讲的事——**SFT（监督微调）**，把它调教成**会应答**的模型，
并对比**全量微调 vs LoRA** 这两种"轴②"的实现方式。

要验证的三个命题：
1. SFT 能让模型从"续写"变成"应答"（学会格式）。
2. LoRA 只用约 1% 的参数，就能达到接近全量微调的效果。
3. SFT **教格式、不注入知识**——答不出语料外的东西。

## 数据：鲁迅问答（`make_qa.py`）

基座模型只"懂"鲁迅语料，所以造它**答得出**的题——补全语料里的句子：

```
问：请补全这句话："我冒了严寒，"
答：回到相隔二千余里，别了二十余年的故乡去。
```

从语料抽句、在逗号/中点处切半，配 3 种问法模板增加多样性。
得到 **14563 训练 + 400 测试**。

## 核心机制：loss 掩码

SFT 还是 next-token 训练，但**只对"答："之后的答案算 loss，问题部分置 -100 忽略**：

```
  [问：请补全…"我冒了严寒，"\n答：]  [回到相隔二千余里…去。 <eos>]
   ✗ 这些位置不算 loss               ✓ 只算这些
```

这样模型学的是"**如何回答**"，而不是"如何复述问题"。实现上就是
`cross_entropy(..., ignore_index=-100)`，把问题位置的标签设成 -100。

## LoRA 实现（`lora.py`）

冻住原权重 W，只训低秩增量 `ΔW = B·A`（B 为 out×r，A 为 r×in，r=8）：

```
h = W·x + (α/r)·B·A·x      W 冻结，只训 A、B
```

- **B 初始化为 0** → 起点 ΔW=0，模型保持预训练原样（自测已验证注入后输出不变）。
- 只给每层注意力的 **W_Q、W_V** 注入。
- 自测：小模型上 LoRA 可训练参数占 5.32%（模型越小占比越高；真实 353 万模型上约 1%）。

## 结果

### 参数量与 loss

| | 可训练参数 | test loss（5.51 →） |
|---|---|---|
| 全量 SFT | 3,536,384（100%） | 4.39 |
| **LoRA SFT** | **32,768（0.93%）** | **4.41** |

**LoRA 用约 1/108 的参数，test loss 几乎和全量一样。** 这就是 LoRA 的核心事实：
微调的"变化量"是低秩的，动 1% 的参数就够。

> 注：test loss 绝对值不低（4.4），因为"精确补全鲁迅原句"本身熵很高
> （下一句有太多种可能）。关键不是绝对值，而是**全量 vs LoRA 几乎相同**。

### 行为转变：续写 → 应答

给同一个"问：…答："提示：

```
[基座]    "车车车车车车…" / "女孩，女孩，女孩…"   ← 只会乱续、重复，不懂要回答
[全量SFT] "但这才知道是飘飘然了。"               ← 简短作答、适时停止
[LoRA]    "却是很容易的，然而我也要看得多。"      ← 用 0.93% 参数也学会了
```

基座模型不知道"问：…答："意味着该回答，只会接着编（甚至陷入重复循环）；
SFT 后两个模型都学会了**给出简短回答并在 EOS 处停止**——格式学会了。

### 知识边界：SFT 不注入知识

问一个鲁迅语料**之外**的问题：

```
问：中国的首都是哪里？
  [全量SFT] "我知道呢。"          ← 答不出"北京"
  [LoRA]    "我在北京中学校里。"   ← 只会蹦鲁迅腔的句子
问：水的化学式是什么？
  [全量SFT] "我在北京中学校里。"   ← 答不出"H2O"
```

**两个模型都答不出语料外的知识**——SFT 只教会了"应答的格式"，知识仍受限于
预训练（只有鲁迅）。这直接印证 `CONCEPTS.md` 第九节：**"SFT 激发行为，
预训练注入知识"**。要真能答"北京"，得先在含该知识的语料上预训练，或用 RAG。

## 诚实的评估

- 模型小、语料窄，SFT 后**答得不准**（补不全原句、偶尔重复）——这是规模限制，
  不是 SFT/LoRA 的问题。
- LoRA 的生成偶有重复（如"然的然的…"），因为贪心解码无重复惩罚、且适配器容量略小；
  加上阶段五的重复惩罚可缓解。
- 重点是**机制验证**：格式学会了、LoRA 省了 108 倍参数、知识边界清晰——三条都成立。

## 运行

```bash
cd stage6_sft
PY=python

$PY make_qa.py                       # 造问答数据
$PY lora.py                          # LoRA 自测（注入后输出不变）
$PY -u train_sft.py                  # 全量 SFT（约 7 分钟）
$PY -u train_sft.py --lora           # LoRA SFT（约 7 分钟）
$PY compare.py                       # 基座/全量/LoRA 三方对比 + 知识边界
```

依赖阶段五的基座（`../stage5_capstone/ckpt_best.pt` + `bpe_best.json`）。

## 这一阶段说明了什么

把 `CONCEPTS.md` 第九、十节落地了：

- **SFT（轴①，目标）**：用 loss 掩码在问答对上微调，让基座从"续写"变"应答"。
- **LoRA（轴②，方法）**：冻住基座、只训 1% 的低秩参数，效果接近全量——
  这就是大模型微调的标准姿势"LoRA SFT"。
- **知识 vs 行为**：SFT 改变了行为（会应答），但没注入知识（答不出语料外的东西）。

至此，你完整走过了"预训练（阶段三~五）→ 后训练/SFT（阶段六）"的 LLM 全流程，
并亲手实现了 LoRA 这个现代微调的核心技术。
