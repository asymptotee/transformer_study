# stage11_datascale —— 11.1 数据对齐:官方语料能买多少能力

承接 9.5 桥接的归因("检索之坎的主闸门是数据量")——把归因从"观察官方模型"
变成"自家受控实验":**同架构、同 10000 步、同 seed、同优化配方,只换预训练
语料**(自家 wiki 150MB → minimind 官方 pretrain_t2t_mini),看同一套 20 题
从 0 破不破冰。

## 实验设置

| | 94_full(stage9 基座) | 11-mm(本实验) |
|---|---|---|
| 语料 | 自家 150MB wiki 散文(18,421 篇) | 官方 `pretrain_t2t_mini`(127 万行指令式问答文本) |
| BPE 词表 | 15,124(在 wiki 上训练) | **19,171(在官方语料上重训)** |
| token 量 | 4,390 万 | **3.015 亿(6.9×)** |
| 结构 | 现代全配 117.8M | 同一结构 120.9M(词表变大 +3.1M) |
| 训练 | 10000 步,seed 42 | 完全相同配方(编码缓存 78 min + 训练 93 min) |

**为什么要换词表**:分词器是数据的压缩器,域外文本会被切碎;词表跟数据走
才是正确做法(代价:跨词表 val loss 刻度不可比——见下,可比性全部转移到
20 题 + 固定裁判)。

## 结果

### 语料内:拟合得很好
- 11-mm 语料内 val **2.267(ppl 9.7)**——注意:与 wiki 系数字(3.776)不直接比,
  词表与语料都换了,loss 刻度不同(要公平得按 BPB)

### 20 题:从 0 破冰(核心结果)

| | 94_full(旧语料) | 11-mm(官方语料) | 官方 minimind-3 64M(9.5 测) |
|---|---|---|---|
| 格式 | raw | raw | chat(它的母语) |
| 真实答对 | **0/20** | **ask ≈4/20、fill ≈1/20** | ≈5/20 |

行级审计(ask 6 个关键词命中,4 真 2 假):
- ✓ 故宫位于哪座城市 → "故宫位于**北京市**海淀区…"(城市答对,套话混杂)
- ✓ 世界上最高的山峰是 → "**珠穆朗玛峰**,位于喜马拉雅山脉的尼泊尔和中国的边境线上"(完整正确)
- ✓ 水的化学式是什么 → "**H2O**…"(低频题!)
- (漏判)珠穆朗玛峰的海拔 → "**8,848米**"(内容对,逗号致关键词未匹配)
- ✗ 秦始皇…朝代 → 复读假阳("秦"来自"秦始皇帝")
- 首都题仍崩("中国首都是中国")——"哪里?"式问句壳在该语料占比低,**模板只半覆盖**

**解读**:官方 t2t 语料本身含"故宫位于…""…是珠穆朗玛峰"式陈述 → raw 的
fill/陈述句式部分落进分布 → 破冰;而"问句壳"覆盖不足 → 首都题照旧。
与官方 64M 的"chat 全覆盖 5/20"**不能直接比大小**——两边都是"格式与语料
部分/完全对齐"的产物。同格式严格对比需 10.3(chat-template SFT),诚实开口。

### 迁移探针(wiki 文本 × 新 BPE 重编码,修正版)
- 11-mm 在 wiki 域:**4.690(ppl 108.9)** vs 语料内 2.267——换域代价 ≈ +2.4
  loss:模型"忘了 wiki 腔"(百科长文续写退化,陌生 prompt 现复读:数学是→"数学…
  数学"、鲁迅是→"世界上最大的动物")
- 但通用事实仍存活:"北京是→中国的首都,位于北京"(跨域高频事实留在参数里)
- 诚实边界:该落差混着"域内容差"与"新词表切 wiki 文本的低效",纯域差需
  wiki×新BPE 对照臂(未训,开口记录);94_full 的 3.776 是旧词表刻度,仅供量级

## 结论

1. **9.5 归因在自家受控实验闭环**:同架构同算力,数据 150MB→3 亿 token(6.9×)
   → 20 题 0 → ~4-5/20。数据是闸门,不是参数规模(stage8 归因二的修正,双证据)
2. **格式即分布的教训在更大语料上同样成立**:语料大也没自动学会"问句壳"——
   破冰来自"陈述句模板的半覆盖",不是模板泛化。想要稳定问答 → chat-template
   SFT(10.3)是下一步的自然实验
3. **换域有代价**:目标域拟合好(ppl 9.7),旧域付出 +2.4 loss;通用高频事实
   存活。真实世界"换语料"要掂量保留旧能力的需求
4. **epoch 视角**:同 10000 步,新语料只看 0.27 epoch(94_full 是 1.8)→ 数据
   还远没学完,官方配方用更大算力;我们的 2.267 只是"读了一遍的 27%"的成绩

## 文件与复现

| 文件 | 内容 |
|---|---|
