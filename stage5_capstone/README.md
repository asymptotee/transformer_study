# 阶段五：Capstone —— 把所学合起来，推到 CPU 的极限

## 目标

前四个阶段分别学了不同的技术。这个阶段把它们**全部组合**，在 CPU 可达范围内
把鲁迅续写推到最好，看看能走多远、天花板在哪。

## 组合了哪些技术

| 维度 | 阶段三/四 | **阶段五 capstone** | 来自 |
|---|---|---|---|
| 分词 | 字符级 / BPE 600 | **BPE 1000 合并**（1.25 字符/token） | 阶段四 |
| 参数量 | 111 万 / 207 万 | **353 万**（d_model=256, 4 层, 8 头） | 阶段四缩放实验 |
| 上下文 | 64 | **128**（看到更多前文） | — |
| 训练步数 | 2000~5000 | **5000** | — |
| 解码 | 温度 + top-k | **+ top-p 核采样 + 重复惩罚** | 新增 |

新增的两个解码技巧（`sampling.py`）：
- **top-p（核采样）**：只保留累积概率达到 p 的最小候选集，分布集中时候选少、
  平坦时候选多，比固定 top-k 更自适应。
- **重复惩罚**：压低已生成 token 的分数，专治"我们也不知道我们也不知道"的循环。

## 结果

### 指标：压缩效率史上最佳

公平对比要换算成 **nats/char**（与分词方式无关，越低越好）：

| 模型 | 参数量 | nats/char |
|---|---|---|
| 阶段三 字符级 | 111 万 | 4.56 |
| 阶段四 字符级 | 111 万 | 4.70 |
| 阶段四 BPE | 119 万 | 4.76 |
| **阶段五 capstone** | **353 万** | **4.38** ← 最好 |

组合拳把压缩效率推到了新高。（训练后期 train 4.14 < val 5.47，开始过拟合——
模型变大了但数据没变多，符合预期。）

### 生成：质的飞跃

```
阶段三 字符级(111万):
  我冒了严寒风的。我就是一个人，只能说，但我就要说……    ← 字级乱接

阶段四 large(207万):
  ……他说出，"你要不肯放去，你不肯说？"赵儿子说。        ← 有对话结构

阶段五 capstone(353万):
  我冒了严寒石片，且以及其余的和暖，我即刻飞在这里。
    伯夷和叔齐早经是乡下人，虽然许多粗疏疏起来了。大约因为春天，
    伯夷总是怯弱不下去；然而比较为什么呢？……单四嫂子轻轻地知道过，
    实在神奇迹是不能的。这佯。然而伊也                  ← 有人物、有文体
```

模型学到的东西令人惊讶：

- **真实人物**：伯夷、叔齐（《采薇》）、单四嫂子（《明天》）、羿（《奔月》）
  ——全是鲁迅笔下角色
- **鲁迅腔**：`然而`、`大约因为`、`倘`、`便`、用 `伊` 代 `她`——标志性用词
- **文体结构**：甚至学会了小说前的注释体——`本篇最初发表于一九二六年……署名唐俟`
  （唐俟是鲁迅真实笔名）
- **对话格式、段落缩进**，且**重复循环消失**（top-p + 重复惩罚生效）

**BPE 在这里功不可没**：因为按词块生成，`伯夷`、`叔齐`、`单四嫂子` 才能作为
完整的词出现，而不是被拆成乱接的单字。

### 诚实的天花板

风格、词汇、人物、文体都学得惟妙惟肖，**但句子之间仍无逻辑叙事**——
读起来像"鲁迅风格的句子随机拼接"，而不是一篇连贯的文章。

这正好印证 `CONCEPTS.md` 的判断：

> 3.5M 参数能把数据压缩到"风格层"（用词、句式、人物、文体），
> 但还到不了"语义/逻辑层"（连贯的叙事、推理）。**涌现还没到。**

要真正连贯，需要的规模远超 CPU 所能——这正是大模型之所以"大"的原因。
但这个项目已经清楚展示了**方向**：每加一份规模/技术，生成质量就上一级台阶
（字级乱接 → 对话 → 人物文体），沿着这条线放大，尽头就是涌现。

## 运行

```bash
cd stage5_capstone
PY=python

# 训练（约 22 分钟：BPE 编码 52s + 5000 步）
$PY -u train_best.py
$PY -u train_best.py --steps 30 --eval-every 10   # 先探每步耗时

# 续写（改进解码）
$PY generate_best.py --prompt "我冒了严寒"
$PY generate_best.py --prompt "鲁镇的酒店的格局" --temperature 0.7 --top-p 0.9
$PY generate_best.py --prompt "在我的后园" --rep-penalty 1.3   # 更强抗重复
```

复用阶段三的 `GPT`、阶段四的 `BPE`、鲁迅语料（`../stage3_gpt/luxun_clean.txt`）。

## 文件

| 文件 | 内容 |
|---|---|
| `sampling.py` | 改进解码：温度 + top-k + top-p + 重复惩罚 |
| `train_best.py` | 训练最佳模型（BPE + 大模型 + 长上下文，全可配置） |
| `generate_best.py` | 用最佳模型 + 改进解码续写 |
| `bpe_best.json` | 学出的 BPE（1000 合并） |
| `ckpt_best.pt` | 训好的最佳模型（353 万参数） |

## 这一阶段说明了什么

把学过的技术叠起来，生成质量逐级上台阶——这是 scaling + 工程优化的合力。
但它也划出了一条清晰的线：**在 CPU 的规模上限内，能把"风格"学到极致，
却跨不过"连贯"那道坎。** 那道坎要靠几个数量级的规模才能跨过，而跨过它的那一刻，
就是 `CONCEPTS.md` 第八节说的**涌现**。
